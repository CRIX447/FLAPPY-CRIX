FLAPPY CRIX - DESKTOP APP
=========================
CRIX STUDIOS

The desktop app is a small Rust program (Tauri) that shows the website game,
crixgamingvr.com/flappycrix, in WebView2: the browser engine already built into
Windows 10 and 11. The old app (2.x) was Electron, which carried a whole copy of
Chrome inside it; this one doesn't, so it is a much smaller download and uses
less RAM. The game itself is the website, so every website update reaches the
app straight away. The Unity version is discontinued.

WHAT'S HERE
-----------
  src-tauri\src\main.rs       the app: windows, which links stay inside, sign-in pop-ups
  src-tauri\tauri.conf.json   name, version, installer settings
  src-tauri\windows\hooks.nsh removes the old Electron app when someone updates
  app\index.html              start page: checks the connection, "can't reach the servers"
  app\splash.html, splash.png the CRIX STUDIOS splash
  src-tauri\icons\            the app icon

BUILD ON GITHUB (easiest, nothing to install)
---------------------------------------------
  1. Raise "version" in src-tauri\tauri.conf.json AND src-tauri\Cargo.toml
     (a version that's already released is refused).
  2. github.com/CRIX447/FLAPPY-CRIX > Actions > "Build Windows app" > Run workflow.
  3. It builds, starts the app to prove it loads the game, checks no debugging
     port can be opened, measures the RAM, and only then PUBLISHES the release.
     A failed run publishes nothing.

BUILD ON YOUR PC
----------------
  Install Rust (rustup.rs) and Node (nodejs.org), then double-click BUILD.bat.
  RUN.bat starts a test copy.

KEYS IN THE APP
---------------
  F5 reload    F11 full screen    F1 about

HOW UPDATES WORK
----------------
  * The game: loads from the website every time, so it is never behind. If the
    website changes while someone is playing, they are offered a restart.
  * The app itself: on start it checks GitHub for a newer release and offers
    the download.
  * Players still on the old Electron app (2.x): their app updates itself to
    this one (the release's latest.yml), and the installer removes the old app.
    They need to sign in again once, because the new app starts with a fresh
    browser profile.
