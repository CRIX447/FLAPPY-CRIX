FLAPPY CRIX — DESKTOP
=====================
CRIX STUDIOS

One app. No launcher, no second download.


WHAT YOU NEED
-------------
Node.js from nodejs.org (LTS). Tick "Add to PATH" during install.
Put icon.ico in this folder. It must be a real .ico, not a renamed PNG.


BUILD ON GITHUB (easiest — no Node needed)
------------------------------------------
GitHub builds it for you on a Windows machine:

    1. github.com/CRIX447/FLAPPY-CRIX > Actions > "Build Windows app"
    2. Run workflow
    3. About 5 minutes later a DRAFT release appears under Releases,
       with the installer, the portable exe and latest.yml attached.
    4. Check it, then press "Publish release". Nobody gets it until then.

Change "version" in package.json before each new release — a release
for a version that already exists is refused.


BUILD ON YOUR PC
----------------
    npm install
    npm run build

Output in dist\:
    FlappyCrixSetup-1.1.1.exe    installer
    FlappyCrix.exe               portable, runs anywhere

If the installer does not appear, NSIS failed to download. Use:
    npm run build:portable


IMPORTANT
---------
Upload the files from dist\, NOT the exe inside win-unpacked.
That one needs the ~100 files around it and will fail with a
missing ffmpeg.dll error if moved on its own.


PUBLISH
-------
Create a PUBLIC repo called crix-desktop, then:

    $env:GITHUB_TOKEN="your_token"
    npm run publish

That builds and creates a draft GitHub release in one step. Publish it
on GitHub when you are happy with it.
Get a token at GitHub > Settings > Developer settings >
Personal access tokens, with "repo" scope.


HOW UPDATES WORK
----------------
Two layers, and only one of them matters day to day.

THE GAME loads from crixgamingvr.com. Push to your website and every
player has it next launch. No download, nothing for them to do. This is
where nearly all your changes go.

THE WRAPPER (this exe) updates through electron-updater. You only need
this for native changes — the icon, permissions, the menu. Rare.


WHAT IS IN IT
-------------
  - The full game
  - CRIX Chat in its own window, Ctrl+Shift+C
  - Stats, notifications and patch notes (already in the game)
  - Menu access to files, terms, privacy and update checking
  - Sign in with Google through your own browser — the app signs itself
    in, because Google blocks sign-in inside apps
  - A "can't reach the servers" screen that reconnects on its own


THE ICON
--------
icon.ico is stamped into the exe by build\afterPack.js. To change it,
replace icon.ico with a real .ico (not a renamed PNG) and build again.
Windows remembers old icons for a while: if the shortcut still shows the
old one after installing, unpin it and pin it again, or sign out and in.
